# Typography specification

- Display family: Space Grotesk, weight 700–800.
- Body family: Manrope, weight 400–700.
- Technical labels: DM Mono, weight 400–500.
- Hero headline: clamp(3.25rem, 6.5vw, 6rem), line-height 0.94–1.0, letter-spacing -0.055em.
- Section headline: clamp(2.4rem, 4.5vw, 4rem), line-height 1.0–1.08, letter-spacing -0.045em.
- Body: 0.9rem desktop / 0.82rem mobile, line-height 1.7–1.9.
- UI labels: 0.65–0.75rem, semibold; never use tiny text for essential content.
- Gradient emphasis: violet → pink → coral. Use real text with background-clip, not text baked into images.
